# CV Match ATS

App gratuita en Streamlit para comparar un CV en PDF, DOCX o TXT con la descripción de una vacante. Calcula coincidencia léxica simple, lista términos presentes/ausentes y ofrece sugerencias responsables.

## Ejecutar

```bash
pip install -r requirements.txt
streamlit run app.py
```

No utiliza APIs externas ni almacena CVs deliberadamente. El resultado es orientativo y no garantiza superar sistemas ATS.
